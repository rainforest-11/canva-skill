## 一、总纲：形式感不是"加点装饰"，是决策顺序

A 视频从头到尾只回答一个问题：**如何在不动原本版面的基础上去增加设计的形式感**（00:00）。
它的潜台词是——先有结构，再谈形式；结构不对，装饰越加越乱。

正确顺序（00:05–00:42）：

1. **定尺寸** — 页面尺寸先定，后面所有比例都依赖它
2. **文案入版心** — 全部文案先放进版心，不加任何装饰
3. **梳理层级** — 谁是主角谁是从属；A 的做法是"重要的展览名称和展览日期都在字号上做放大处理"
4. **定结构** — "确定信息与信息之间的空间关系"
5. **搭建版面** — 按结构把块排出来
6. **才开始加形式感** — 色彩、纹理、分割、装饰、文字图形化、图文互动

**这条顺序是可以直接照抄的作业流程。** 跳过 3、4 直接进 6，就是 A 视频 03:46 那两个反面例子的成因。

## 二、形式感的八级杠杆（按侵入性递增）

A 视频实际上把一个版面的"可加形式感的旋钮"穷举了一遍。每个旋钮都能单独用，也能往上叠。

### 1. 排版本身的疏密与错落（改动最小）

标题**分散排列**即可增加变化性。A 给的前提条件很关键：
"由于标题的字号与其他信息的字号区分得足够的明显，所以即使标题分开来了，也不会太影响其余阅读性"（00:47）。
→ **分散的前提是字号落差够大**，落差不够就别拆。

### 2. 色彩：先换面积最大的那块

纯文字版面加色只有三种方式（01:14）：**填充背景、填充文字、局部填充**。
"由于面积的关系，背景换色所带来的冲击感是要大于文字换色的"（01:20–01:24）。

**色调决定形式感强弱**（01:39–01:51），这是 A 给出的明确排序：

| 色调 | 色相感 | 形式感 |
| --- | --- | --- |
| 纯色调 | 最强 | 最强 |
| 明色调、淡色调 | 中 | 中 |
| 淡浊色调、浊色调、暗色调 | 弱 | 弱 |

黑白灰属无彩色系，"如果从色彩的角度探讨形式感的话，那么黑白灰肯定属于形式感最弱的那一批颜色"（01:04–01:07）。
→ 想要"极简高级"可以走黑白灰，但那是**放弃了色彩这条杠杆**，得靠排版和图文关系补回来。想快速出效果，先上纯色调。

### 3. 色彩对比：比换色更省事

- **互补色**：A 的示范是背景换黄色 + 文字换互补的蓝色（02:07–02:13），"形式感得到了进一步的加强"
- **对比色**：效果也不错
- **金赤色**：红黄这组"非常吵零的经典搭配"（02:20，应为"非常经典的搭配"）
- **渐变**：不同渐变方式的视觉冲击力不同；还有**异形渐变**（02:33）

### 4. 纹理：注意力度，可以叠

素材来源（02:45–03:03）：揉皱的纸张、石头表面、平头笔刷刷痕、整张纸、水彩、墨迹、手绘板线条。

力度是这条杠杆的核心（03:05–03:15）：
- 太弱 → "左边的海报肌力就显得有些太弱了"
- 太强 → "右边的纹理就太喧宾夺主，大家更看不到前面的文字了"

**用层数控制强度**（03:17–03:26）："纹理是可以多层叠加的，我们可以通过控制纹理叠加的层数，来控制纹理的强弱程度"，范例用了三层不同纹理。

也可以自己造肌理（03:30–03:42）：**点阵、网格、放射线**，觉得单调就再加变化增加背景细节。

### 5. 分割版面：必须有依据

两个反面例子（03:46–03:59）：
- 左：**分割方式与版面结构不匹配**
- 右：**色块色彩凌乱** + **切割方式不统一**

正确依据（04:06–04:24）：均等划分"会略显普通"；
改为不均等划分后，"画面中就会出现强弱的变化，人们的视线会更倾向于被更大的面积所吸引，然后再看向小的面积"。

**光有面积还不够**（04:39–04:44）："我们也需要在色彩和位置上去进行强调，这样才能让观者保持稳定的视觉入口。"
→ 面积给强弱，色彩+位置给**入口**。少了入口，读者不知道从哪看起。

三种常见分割（04:48–05:07）：**强调**（依视觉强弱分）、**错位**（增加变化性）、**层叠**（增强层次感）。

### 6. 色块与线框：只强调信息，不要铺满

思路切换（05:10–05:16）："抛开版面中的留白空间，我们只强调信息的部分。"
最简单直接的做法是**用色块框选文本中的信息**。

变化（05:33–05:55）：
- 不同**形状**的区分 → 色块之间产生差异和对比
- 色块**换成线框** → 效果不错
- 形状与线框的差异 → "给予文字不同程度的强调"，而且"更有趣味性"

### 7. 点线面装饰

- **点**（06:08–06:20）：有占据空间的作用，装饰属性强，加了点"会显得相对更加灵动"，是烘托氛围的有力工具。**不一定是小圆形**——"相对较小的图形，都能看作点元素"
- **线**（06:24–06:33）：除分割和连接外也有装饰属性。**下划线强调主标题**；较小的文字用**细一点的线**强调
- **面**（06:39–07:25）：视觉强度大，"不一定要把页面全都排满"。可以给面积赋予内容（舒展的照片画面），也可以是几何图形；
  几何图形互相组合形成丰富造型；嫌简单就加**渐变色、粗糙化的轮廓肌理、大小对比**；
  多个不同图形结合**缩放变化**形成"元素掉落的节奏感"；也可以用有特殊含义的小图形

### 8. 文字图形化（改动最大，效果也最强）

原理（07:39–07:52）："如果当文字被放大到一定程度时，我们就会开始去关注它之前没有被注意到的细节部分，文字也就开始变得陌生了起来。"
字母 B 撑满整个版面后，"我们观看它的模式就会切换成观看图形或者观看图像的状态了"→ **可以迅速做出一系列海报**（同一字形，换色换裁切换文案）。

进阶手法（08:04–09:16）：
- 文字填充周围**负空间**，处理好衍生图形
- **重复构成** + "利用页面的边缘对这个图形做一些裁切和呼应"
- 关于遮挡的反直觉结论（08:21–08:30）："那些被遮挡住的信息非但不会被削弱，反而会吸引更多的注意力"——因为好奇心
- **完全几何化的解构再创造**：把字母均匀划分到版面 → 对造型解构再创造 → "虽然它看着很几何，但是其实我们也可以从中找到字母的轮廓"
- 太杂乱时的收口（09:04–09:13）：问题出在颜色上，"经过对色彩的精减和弱化，我们就能得到一版风格清晰、内容更易于识别的版面"

## 三、图文互动的四种关系（A 视频后半段，最实用的一节）

这一段回答"图形和文字怎么放在一起才不生硬"。四种，从简单到复杂：

### 叠压（09:26–09:45）
图文直接叠，图形挡住文字。**关键在于调整图形造型让遮挡不伤害内容**：
"为了让遮挡的部分尽量不影响到后面的内容，我们可以将书本的造型调整成这个样子"，最后填充背景色收尾。

### 穿插（09:50–10:32）
让文字和图形产生前后层次。做法是先取概括图形：
"一个物体的光影可以被划分成明、暗、灰三种色调。这里我们可以通过省略其中暗部的轮廓，从而得到一个概括性的图形"。
然后把**一部分文字重新叠压到图形之上**，形成四层：

```
最顶层   白色文字
第二层   图形
第三层   黑色文字
最底层   背景
```
A 的评语："整体看上去，层次感是不是更加丰富了呢"（10:32，"城市感"应为"层次感"）。

### 透叠（10:36–11:04）
"就是调整图形的透明度，让原本被遮挡住的元素重新显示出来。"
A 的比喻很好用：把版面想象成书架，"真实的书架应该是这样凌乱一些的，有些倾倒在一旁，有些横放在里面"→ 图形不只是装饰，它在**讲一个场景**。
最后排入文字、调低透明度收尾。

### 正负空间（11:19–11:53）
最高级的一种：**既实现透叠，又让被压住的内容显示在顶部**。
"A 就既实现了图文的透叠，又能够让被压住的内容显示在顶部。"
落到实操："确定好版式结构之后，我们要做的是让被叠压的部分，重新恢复到图案顶层来。"
图形可以是抽象几何，也可以是具象图案。

## 四、B 视频的实操骨架（改模板路线）

A 是在说"怎么做设计"，B 是在说"怎么在可画里 10 分钟做完一张能用的招新海报"。它的价值在于**改模板的标准动作**，不是从零创作。

### 五步流程

| 步 | 动作 | 细节 |
| --- | --- | --- |
| 1 建 | 创建设计 → 海报 → 命名 | 搜模板关键词（本例"招新"）；**复制一份再改**，保留原件 |
| 1.5 清 | 调整位置 → 选不需要的图层 → Delete | 先把模板里不属于自己的元素删干净 |
| 2 字 | 替换文案 → 调文字框位置 | 正文：思源宋体加粗 **28**；小标题：加粗 **34**；**复制样式**统一；**设为左对齐**便于框对齐 |
| 3 材 | 上传素材 → 新建文本框 | 英文用 **Impact**（"字体较粗，比较好看且醒目"）；装饰英文文本设白色 + **轮廓特效**（粗细 105） |
| 4 调 | 图层与位置微调 | 见下 |
| 5 出 | 导出 PNG（当前页面） | |

### 步骤 4 的图层纪律（最值得抄）

- 复制边框：**按住 Alt 拖动**即复制
- 插图置顶：`Ctrl + 左中括号` 前移一层，`Ctrl + Shift + 左中括号` 置顶
- 层级关系要服务版式：把 "join us" 图层调在边框**前面**
- **一条硬经验**（06:20）："建议调整文字框的时候，先将图层移到最前，调整完成后再移回后一图层。"
  → 被压住的文字框直接拖拽会点不中，先置顶调好再送回原位。这条能省掉大量时间。

### 试错留痕（有用的部分）

- 想给徽章做"白色 + 蓝色轮廓"，**实际效果不行**，最后换成**蓝色 + 阴影**（08:10–08:40）
- 最后又调整了画笔位置和大小、加了院徽（08:40–09:11）
- 说明：**轮廓特效在有底色的元素上容易糊**，阴影比轮廓更稳

## 五、把思路转成 Canva MCP 的操作

`generate-design` 吃一句自然语言。从上面提炼出的教训是：**堆形容词没用，要给结构决策**。

差的 query：
```
一张好看的科技风海报
```
好的 query 按 A 的六步顺序写，把八级杠杆里**你打算用的那几级**写清楚：
```
2026 技术分享会海报，竖版。
层级：主标题「XXX」最大，时间次之，主办方最小。
色调：纯色调深蓝底 + 橙色互补强调。
分割：不均等三分（上方 60% 主视觉、中层 25% 标题、底部 15% 信息），
     标题区左上角为视觉入口。
装饰：网格肌理叠加两层，弱；底部一条细线分隔。
```
每一句都对应一个可验证的版面决策，生成结果才好比对、才好提修改意见。

### 用 edit-design 落地八级杠杆

| 杠杆 | 对应 operations |
| --- | --- |
| 字号层级、分散排列 | `format_text`（font_size/font_weight/line_height）、`position_element` |
| 背景换色 | `recolor_element` 或 `insert_shape` 铺底 + `recolor_element` |
| 互补/对比色 | `format_text` 的 `color`、`recolor_element` |
| 分割线、线框 | `insert_shape`（path 画线/框）、`update_stroke_properties` |
| 色块框选信息 | `insert_shape` 在文字下层 + `layer_element`(`back`) |
| 点元素装饰 | `insert_shape`（小圆/小图形）+ `update_opacity` 控制重量 |
| 图文叠压/透叠 | `update_opacity`（透叠）、`layer_element`(`front`/`back`)（叠压与穿插分层） |
| 文字图形化 | 不好用 API 做，走 `generate-design` 直接生成 |

**透叠和穿插靠的就是 `update_opacity` + `layer_element` 两个操作**——`layer_element` 的 `position` 只有 `front`/`back`，需要多层顺序时要按从下往上的顺序逐个调，一次只能移一层到最前/最后。

## 六、可执行的检查清单

做完一张，按 A 的顺序自检：

1. 尺寸定了吗？文案都在版心里吗？
2. 字号层级有几级？主角是不是最大？
3. 信息之间的空间关系是**决定的**还是**顺手排的**？
4. 这一版用了哪几级杠杆？有没有一级都没用就交稿？
5. 如果是黑白灰：靠什么补形式感？（排版/图文关系/纹理）
6. 有分割/色块吗？分割方式和版面结构匹配吗？色块色彩凌乱吗？
7. **视觉入口在哪？**（A 的标准：面积 + 色彩 + 位置三者要一致地指向入口）
8. 纹理/装饰的力度：太弱还是喧宾夺主？
9. 图文关系是叠压、穿插、透叠还是正负空间？有没有生硬贴合？
10. 遮挡的地方会不会伤到内容？
