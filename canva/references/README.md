# references/ 索引

做 Canva 设计时按需查阅的参考资料。

| 文件 | 内容 | 什么时候读 |
| --- | --- | --- |
| `poster-thinking.md` | 形式感八级杠杆、图文四关系、改模板五步、Canva 操作映射表 | **每次做海报** |
| `design-fundamentals.md` | 色彩、排版、字体、图形/透视、标志五章 + Canva 落地表 + 自检清单 | 判配色/字距/选字体/图形关系时 |

两份方法论文档是互补的：`poster-thinking.md` 讲**决策顺序和可调杠杆**，
`design-fundamentals.md` 讲**每个杠杆背后的原理和边界**（为什么这个颜色不行、这个字距为什么读起来累）。
