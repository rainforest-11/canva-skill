## 一、色彩：先判断"适合"，再谈"好看"

### 1.1 HSB 三轴是唯一需要的色彩坐标系

（BV1oV411p7AW 00:00–01:30）

| 轴 | 含义 | 极值 |
| --- | --- | --- |
| **H 色相** | 0–360 度色轮，即"全部颜色" | 红 0° / 绿 120° / 蓝 240° |
| **S 饱和度** | 纯度。S→0 变灰 | 0 = 灰，100 = 纯 |
| **B 明度** | 亮度。B→0 变黑 | 0 = 黑，100 = 最亮 |

掌握 HSB 就能**反向构造**任何想要的颜色印象。
例：所谓「男生最喜欢的蓝色」= 中高明度 + 降饱和 → 莫兰迪灰蓝。

### 1.2 核心命题：不是颜色丑，是不适合

（BV1oV411p7AW 01:00–01:40）

> 红色在口红里毫无不协调；红配某些语境就丑。

所以选色的第一步不是"挑个好看的"，而是**确定要传达的色彩印象**：
行业冷暖、红色=喜庆/警示、紫色=神秘、蓝色=科技/信任。

### 1.3 色轮关系与"烂眼睛"问题

- **120° = 对比色**
- **180° = 互补色**
- 两者**直接硬用会烂眼睛**

破解强制配色冲突的三步（顺序不能反）：

1. 先降**饱和度**
2. 或降**明度**
3. **最好两者一起调** → 可选范围变大
4. 最后再调**色相**（利用冷暖倾向差异）

### 1.4 颜色的加减法与 6:3:1

（BV1oV411p7AW 01:50–02:20）

加法 = 加点缀色，形成三级结构：

```
主色 60%  +  辅色 30%  +  点缀色 10%
```

- 渐变是另一种加法；**对比色不适合做渐变**（过渡带会脏）
- **面积法则：先改面积最大的那块**（背景 > 文字）

### 1.5 四个色调象限（最重要的一张表）

（BV1oV411p7AW 02:20–结尾）

| | 高 B（亮） | 低 B（暗） |
| --- | --- | --- |
| **高 S（纯）** | **纯色调** — 冲击力最强 | **深色调** — 沉稳、力量 |
| **低 S（灰）** | **浅色调** — 清爽、温柔 | **灰/浊色调** — 高级、克制 |

用法：**给每个象限打印象标签，按内容需求去对应区域取色**，而不是先挑色再套内容。

> 注意：黑白灰属无彩色系，是**形式感最弱**的一档。走极简可以，但那是主动放弃了色彩这条杠杆，得用排版和图文关系补回来。

**在 Canva 里**：`format_text` 的 `color`、`recolor_element`、`insert_shape` 铺底。改色前先问「这是六成面积还是那一成点缀」。

## 二、排版：眼睛怎么读，你就怎么排

### 2.1 阅读不是逐字理解，是把整段当一个区域扫

（BV13M4y157Xc 00:22–00:59）

眼睛的实际动作：跳焦点到行首 → **快速笼统地扫一片** → 理解这片加在一起的意思 → 遇到陌生词多停一会 → 换行 → 重复。

**所以排版的唯一 KPI 是「让读者能快速定位」。**

### 2.2 字距与行距

- 字距过小 → 文字糊一起，难以分词
- 字距**比行距还大** → 破坏"一段"的区域感，读起来很累
- **不要改字体默认字间距**——字体在设计时对每个字母的默认间距做过精细调整，非必要不动

### 2.3 每行多少字

| 问题 | 后果 |
| --- | --- |
| 每行太多 | 读完回行找不到头 |
| 每行太少且行数多 | 混乱 |
| 行数少 + 每行少 | **可以一次性捕捉多行一起读**（最佳） |

### 2.4 断行与断段

- 胡乱换行会**斩断一个完整的词**
- 每行结尾都按词换行 → 给读者一个强烈的「这里断行请注意」的暗示，反而干扰
- 中文**没有"齐头散尾"的传统**，尾部大幅长短不一会让读者难以接受
- 断段两种做法：**段首空两格**，或**段间空一行**
- ⚠️ **段首不要敲 4 个英文空格**——空格宽度和汉字之间不存在倍数关系。用全宽空格（或排版引擎的缩进）
- 数字设备上换行结果不定，末行孤字难免，这是客观限制

### 2.5 中西文混排的三个细节

（BV13M4y157Xc 03:49–05:10）

1. **西文逗号、句号、分号后面必须加空格**。不加会被误读成网址或缩写
2. **中文与西文/数字之间要留空隙**，约 **中文字格 1/4 宽** 最舒适。直接敲一个半角空格只是折中方案（苹果系统会自动处理）
3. **标点看语境**：中文语境用中文标点，英文语境用英文标点

### 2.6 专有名词的大小写

写错 → 词汇变陌生 → 该区域观察时间加长 → **降低阅读效率**。这是效率问题，不只是美观问题。

### 2.7 视觉动线：版面的第一决策

（BV1FZ4y1g74Y 全篇，排版三部曲之一）

> 任何版面只可能由两种东西组成：文字或图像。

加了第二个元素，读者就有了选择。**你必须在设计上控制这个选择。**

**第一步永远是设计视觉落点**：先图后文，还是先文后图。

> 「很多觉得自己排版杂乱无章的设计师，其实就是因为在一开始便放弃了掌握视觉动线的权利。」

元素多时的处理顺序：
`整理信息 → 区分主次 → 确定真正的落点 → 划分段落 → 设计阅读顺序`

段落内部的元素要**显得是一家人**：规律间距，或适当重叠（重叠的前提是不能影响阅读；大面积文字压盖其他文字一般别干）。

### 2.8 反直觉技巧：元素越小越好排

（BV1FZ4y1g74Y 01:47–02:19）

> 排版自由度高的时候，**要试着找到每个段落内元素的最小尺寸**。这是一个重要技巧。

- 人们常按电脑屏幕的观感定字号，**错误预估最小尺寸** → 读者无法确定落点
- 有些信息「仅仅是想阅读的时候能完成阅读就足够了」
- 元素越小 → 越容易创造美观排版 → 越能突出重要信息
- 用尽可能小的尺寸排版时，「曾经那些怎么摆都不舒服的东西似乎变得听话了很多」

### 2.9 别迷信网格

> 「不要什么版面都依靠所谓的网格系统去排版，那只会让你变得平庸。」

两种排版范式：
- **推理式排版** — 设计读者视觉动线（本节全部内容）
- **创造式排版** — 为画面创造主题 / 构图规律 / 故事（下一层）

### 2.10 西文排版四忌

（BV1iL4y1G7WB）

| # | 禁忌 | 原因 |
| --- | --- | --- |
| 1 | **乱动单词内部字母间距** | 字体文件带 kerning（字偶间距）。13 世纪文字就以**竖线为节奏均匀划分**（text 一词源自 textile 编织）。I 字框最窄=1 条竖线、N=2 条、M=3 条。大写 T 左右下角空，不开 kerning 时 T+O 距离巨大 |
| 2 | **胡乱断开单词** | 连字符断词有规则，软件会自动判断；手断要查字典 |
| 3 | **用英文直引号** | 打字机时代为省键位的历史产物，欧美称「傻瓜引号」 |
| 4 | **逗号句号后不加空格** | 基础中的基础 |

补充：
- `tracking` 只用于均匀拉开；**正文不要轻易改默认 tracking/kerning**（标题字、字标除外）
- 两端对齐的正确做法：**单词整体不动，只均匀加宽空格**

**在 Canva 里**：`format_text` 的 `line_height`（0.5–2.5）、`list_level`、`text_align`、`letter-spacing` 不可直接调（用不同字重的字体替代）。视觉落点靠 `position_element` + `resize_element` 控制。

## 三、字体：汉字的结构是可以算出来的

### 3.1 字身框 / 字面框 / 字面率

（BV1Xa411w7HU 00:34–01:35）

| 概念 | 定义 |
| --- | --- |
| **字身框** | 每个活字金属块占据的方块（字帖的方格、软件里的高亮块） |
| **字面框** | 字面实际占据的最大面积，是假想的第二个框 |
| **字面率** | 字面框 ÷ 字身框。**决定默认字间距** |

字面不会填满字身——如果全填满，视觉上反而不舒适：
国字贴边显大、金菱形四角空显小、下字倒三角显偏高 → **逐字微调**，达成视觉统一。

### 3.2 从"6000 个汉字叠在一起"读出的结构规律

（BV16A411H7Cj，字体工作室三言发起的实验）

实验方法：6000+ 汉字各给低不透明度层层叠加，叠到稳定图案为止（继续叠只增浓度）。

从叠加图能读出的东西：

| 读到的 | 说明 |
| --- | --- |
| 模糊的最外边界 | **字面框** |
| 左侧最明显的竖线 | 汉字**左窄右宽结构占多数**（木字旁/提手旁/土字旁/竖心旁），左窄侧中轴带竖画 |
| 右侧较弱的竖线 | 较宽一侧的中轴 |
| 两条竖线合称 | **第二中心线**，其距离反映**中宫大小**（紧凑程度） |
| 中轴线 | 只来自左右对称的字，**左右结构根本没有中轴线** |
| 上下两条明显横线 | 来自上下结构（草字头、金字头占绝对主导，宝盖头也明显） |
| 中间的灰几乎均等 | 汉字横画在垂直方向分布**无明显规律** |

直笔画要**向内收缩**：一个字最外侧一笔是直线时，收一点才显得和别的字一样大（视觉错觉补偿）。

### 3.3 字体家族与视觉修正

（BV16A411H7Cj 03:36–04:10）

- **字重（自重）= 笔画粗细**；整体黑度反映自重
- 宋体总体比黑体浅，因为**横画设计得比竖画细**
- 同一家族里**字重升级时字面也相应增大** —— 这是视觉修正，目的是让同字号下不管粗细看起来都一样大

### 3.4 汉字正文字体四大类的叠加特征

| 类别 | 叠加特征 |
| --- | --- |
| 楷体 | 整体呈**梯形**，右下角尾巴非常明显（捺的顿笔重） |
| 仿宋 | 介于楷宋之间 |
| 宋体 | **最接近四方块**，字面率大，相对易读 |
| 黑体 | 方正规整度最高 |

从楷 → 仿宋 → 宋 → 黑，**逐渐变得方正规整** —— 这大致反映的就是汉字字体的历史演变。

手写感字体叠加大都呈**圆形**；日文假名源自汉字草书 → 圆润有提形但无右下顿笔、右上着点强；
女书纵向书写、笔画清斜 → 叠加无方块感，但内部菱形网格可见。

### 3.5 字体的历史一句话版

（BV15L4y1V7hm）

雕版 → 刻本。宋代三大产地：浙江（欧体，像刀切、好刻）、福建（颜体，多宝塔碑一路、工匠易掌握）、四川（颜字架子 + 柳公权成分）。
明代出现方体字 = 宋体，从宋代刻本体脱胎，**诞生的主因是直线容易刻**（圆转笔画刻起来麻烦）。
黑体历史很短且是舶来品（日本哥特体 → 中国黑体）。民国丁善之兄弟创「聚珍仿宋」，影响至今。

> 结论：**没有哪种字体会永远站在 C 位**。哪种字体流行，看的是它在当前时代的功能表现。

### 3.6 字体设计的细节词汇（判断字体气质时用得上）

（BV1Xa411w7HU 02:20–04:10）

- **中宫**：笔画紧凑程度。中宫松 → 通透省力；中宫紧 → 紧凑有力
- **口字出角**：下出角显**稳定**；去掉出角显**简洁现代**
- **油墨陷阱**：早期字体在角落做复形缺口，让油墨浸润时刚好填平 → 更清晰。现代已非必要，常作装饰保留
- **喇叭口**：照排时代笔画端头加的突出结构（反复拍照会让笔画失真）。同样是历史遗存
- **错觉补偿**：同宽横竖交叉时竖线显得更细 → 加粗；撇穿过横时看起来错位 → 两端适当偏移

### 3.7 如果要从零设计一套字，从哪个字开始

（BV1Xa411w7HU 04:28–05:10）

1. **永**（永字八法）— 含汉字可能出现的大部分笔画，本身稳定端庄，一个字定下整套气质
2. 然后处理**极端情况**：
   - **国 / 金** → 定字面范围（方形 vs 菱形）
   - **我** → 推导内部空间划分
   - **然** → 含各种各样的点
   - **枫** → 含较难处理的笔画和结构
   - **鼎 / 鬱** → 横竖笔画特别多的情况
   - **囊** → 上下左右包围各种嵌套结构

汉字数量参考：常用 3000+ / 商业级字库 6763 / GB18030 70244 / Unicode 92856，
而 OpenType 单文件上限 65535 → 想做全集必须拆多个字体文件。

**在 Canva 里**：字体不能自定义，只能从字库选。判断选哪套时用上面的词——要"稳定庄重"就选口字出角明显的宋/黑，要"现代简洁"就选出角弱化、中宫略紧的。

## 四、图形：重叠、曲线、空间

### 4.1 两个图形重叠的所有可能

（BV1jU4y1s7kt）

| 运算 | 结果 | 用途 |
| --- | --- | --- |
| **加法**（并集） | 融合成一个新形 | 组合出全新结果 |
| **减法**（差集） | 从下层剪掉上层 | 让剪后图形像某物；**妙处是还能兼顾被剪掉的那块像什么** |
| **交集** | 只保留重叠部分 | 小空间里出形 |
| **互补** | 只保留未接触部分 | 与交集互补，可用于系列化 |

**负空间**是减法的高级用法：联邦快递把 E 和 X 之间做出箭头（「当人们发现这个小彩蛋时，会觉得这是一个很有趣的标志，而不仅仅是几个字母」）。

### 4.2 混合模式就是数学运算

（BV1jU4y1s7kt 01:28–06:40）

| 模式 | 运算 | 极端情况 | 用途 |
| --- | --- | --- | --- |
| **正片叠底**（Multiply） | RGB 浓度相乘 | 白消失、黑保留 | 提取黑、压暗、去白底 |
| **滤色**（Screen） | 反转 → 相乘 → 再反转 | 黑消失、白保留 | 提取白、提亮、去黑底 |
| **叠加**（Overlay） | 50% 灰为基准，>50 提亮 <50 加深 | 50% 灰隐形 | **中性灰修图法** |

正片叠底让白消失提取黑，滤色让黑消失提取白，**结果完全相反**。

印刷侧的两个坑：
- **CMYK = CMY + K**（单色黑）。因为 CMY 组成不够黑。四色灰度胶片叠印就是正片叠底
- 套印不准时，细小的四色文字会糊 → 改用单色黑（还快干）→ 但其他通道会镂空白边 → 把这些文字改成正片叠底混合（100% 明度 × 原色 = 原色，文字从胶片消失），代价是透底、黑不够黑，需按经验微调
- **龟纹**：单色网点 45° 没问题，多色网线角度不合理会产生意外花纹，是印刷禁忌

技术流应用：二维码上加掩码（同色为白、异色为黑）避免装饰图形干扰定位点扫描。

### 4.3 曲线：什么样的圆角才算顺滑

（BV19i4y1c76i）

圆角矩形 = 四分之一圆连接直线，但**接缝处过渡不自然**。
解法是缓冲曲线（羊角螺线）：**曲率连续**。

| 级别 | 含义 |
| --- | --- |
| **G0** | 点与点贴合 |
| **G1** | 点连续 + 相切（方向一致） |
| **G2** | 曲率连续变化 |

通俗版：**让曲率以"先慢后快"的方式达到峰值** —— 和动画的速度曲线完全同构（匀速生硬，突然加速再缓停就丝滑）。

贝塞尔曲线（法语发音更准，别念"贝塞尔"的英语重音）本质是设点后插值拧合。钢笔工具 = 去掉三次贝塞尔曲线内部的杠杆：起终点是节点，另两点是手柄。

**绘图规范（字体设计里尤其重要）**：
1. 节点尽量放在**极致点**（水平/垂直极值处）
2. 手柄保持**水平或垂直对齐**
3. 这样只需调手柄长度就能拟合，低分辨率屏幕的显示算法也按此优化
4. **在满足效果的前提下尽可能减少节点数** —— 反例：三段节点中间那个点「就是徒增烦恼」，删掉拉长两端手柄即可

手调优化曲率连续：每个节点向内偏移 + 适当拉长手柄。

### 4.4 透视：三种投影，各自用途

（BV1Y54y1j7dH）

**透视投影**（有灭点，近大远小）：

| 灭点数 | 做法 | 特征 |
| --- | --- | --- |
| 一点 | 方形端点连灭点 | 正面平视 |
| 两点 | 两个灭点 | **竖线仍平行** → 竖线未受透视影响 |
| 三点 | 再给竖线加灭点 | 仰视/俯视 |

- **焦距**：越小视角越大。游戏里"加速"就是缩短焦距制造"跑得更快"的假象
- **希区柯克变焦**：动态调焦距强化紧张不安
- **广角透视**：近处焦距短、远处逐渐变长 → 极强视觉冲击

**平行投影**（无灭点，不变形）：

- 战棋/MOBA 拖拽视野用它，远处不变形
- **轴测图**：任意两条坐标轴投影夹角均 120° → 工程制图/技术制图
- 可用来画**不可能图形**（视错觉）
- 只朝某一个面 → 建模软件的各个视图，**适合横卷轴**（但俯视就穿帮，一看是纸片）
- **倾斜投影**（移轴镜头原理）：视角不变形但增加倾斜角度 → 同样尺寸画面能装下更多内容，配合景深做出"小人国"效果

### 4.5 渐变的抖动原理

（BV1Kb4y1C7fo）

- 1080P 图约 **50 万种**颜色
- 8 位色时代只有 **256 色**，不同系统调色板不同 → 达成共识的 **Websafe Colors**：RGB 各取 `00/33/66/99/CC/FF` 组合，共 **216 色**
- 只给你两种颜色做连续渐变？用**抖动 / 仿色（dithering）**：以不同样式、不同疏密的平铺图案，产生更多颜色的**视错觉**
- 出现明显**色调分离**（banding）= 受调色板限制且未做仿色
- 24 位色（1600 万色）时代仿色仍有用：**减少颜色数量 → 缩小文件 → 加快网络传输**

### 4.6 标志设计的六条路径

（BV1aT4y1w7yL）

1. **字体路径**：选现成字体，或自己设计一套专属的
2. **立体化**：纯文字显扁平 → 加厚度、强化透视与空间感（「不要拘泥于平面」）
3. **首字母**：信息精简，用首字母当主体。抽象也没关系——「**标志的寓意和准确传达信息是两码事**」
4. **抽象图形**：找名字中有特点/有规律性的图案。**越是抽象的标志，越容易阐述它的寓意**。可以「先创作出外观满意的图形，然后再对其进行分析，解释它的寓意」
5. **元素融合**：名字缩写 + 象征物。没有合适的象征物就**自己创造一个具象的**（肖像、像素风都不错）
6. **文字组成图形 / 图形组成文字**（双向都成立）
7. **负空间**（见 4.1）
8. **动态标志**：纸质无法运动 → 抽关键帧做**序列标志**

> 两条心法：
> ① 合格标志的第一步是**先满足氛围和品牌感受**，不要为了追求寓意而创作标志
> ② **不要把时间消耗在优化某一款还没确定的方案上，而是尽可能多尝试方案** —— 这样才可能遇到更合适的那一个

## 五、形式感：八级杠杆与图文四关系

节选自 `poster-thinking.md`（来自研习设《10 分钟做 72 张海报》），此处只放索引。

**决策顺序（不可跳步）**：
`定尺寸 → 文案入版心 → 梳理层级 → 定结构 → 搭建版面 → 最后才加形式感`

**八级杠杆（侵入性递增）**：
1. 排版疏密错落（**前提是字号落差够大**）
2. 色彩（先换面积最大的：背景 > 文字）
3. 色彩对比（互补/对比/金赤/渐变）
4. 纹理（**用层数控强弱**：太弱=没有，太强=喧宾夺主）
5. 分割版面（**不均等划分**产生强弱 + 色彩位置给"视觉入口"；三种：强调/错位/层叠）
6. 色块线框（只强调信息，别铺满；形状差异 + 线框替代）
7. 点线面装饰（点不必是圆，小图形都算；线可做下划线强调主标题）
8. 文字图形化（放大到观看模式从"读"切换到"看图"）

**图文四关系**：叠压 → 穿插（省略暗部轮廓得概括图形，形成白字/图形/黑字/背景四层）→ 透叠（调透明度）→ 正负空间（透叠 + 被压内容显示在顶部）。

**一条反直觉结论**：遮挡**反而**吸引注意力（好奇心）。
**一条收口技巧**：版面太杂乱时，问题通常出在颜色上，「经过对色彩的精减和弱化」就能得到风格清晰的版本。

## 六、跨主题的五条硬结论

1. **色彩看象限，不看喜好**：先定要传达的印象，再去四象限对应区域取色。不是颜色丑，是不适合。
2. **排版的 KPI 是定位速度**：读者是扫区域不是读单字。字距行距断行断段全部服务于"读者能不能快速定位"。
3. **越小的元素越好排**：先找每个段落内元素的最小可用尺寸，再谈美观。这是排版自由度高时最重要的一手。
4. **中文字体是几何可算的**：字面率、中宫、第二中心线三条指标就能判断一套字的气质与适用场景。
5. **多做方案，少雕一个方案**：无论标志还是海报，把时间花在探索上比花在打磨一个未确定的方案上回报高得多。

## 七、在 Canva MCP 里怎么落地

| 学到的规则 | Canva 操作 |
| --- | --- |
| 字号层级 / 视觉落点 | `format_text({font_size, font_weight})` + `position_element` |
| 主色 60% 辅色 30% 点缀 10% | `recolor_element`（面积最大的先改）+ `format_text({color})` |
| 分割版面（不均等） | `insert_shape` + `update_fill`，或直接 `add_page` 分区 |
| 色块/线框强调信息 | `insert_shape` 置于文字下层 + `layer_element({position:"back"})` |
| 纹理用层数控强弱 | 多次 `insert_shape` + `update_opacity` |
| 点元素装饰 | `insert_shape`（小图形）+ `update_opacity` 控重量 |
| 图文叠压 / 透叠 | `layer_element({position:"front"/"back"})` + `update_opacity` |
| 文字图形化 | API 侧做不精确，交给 `generate-design` 生成 |
| 曲线顺滑（圆角矩形） | `insert_shape` 的 `path`（只支持 M/L/H/V/C/S/A/Z，Q 和 T 不支持，**用 C/S 或 A 代替**） |

**没有直接对应能力的三件事**（别硬做，换路径）：
- 字偶间距 / tracking 微调 → 换字体或换字号层级
- 混合模式（正片叠底/滤色/叠加）→ 在外部处理好图片再 `upload-asset-from-url`
- 自定义字体 → 用图库字体，靠字重和层级制造差异

## 八、自检清单

出图前：

1. 这一版的核心色彩印象是什么？落在哪个象限？
2. 主色/辅色/点缀面积比是不是 6:3:1？建议改色时先问「这是六成还是一成」
3. 视觉落点在哪？读者第一眼看什么？**这是被决定的还是随手排的？**
4. 字距行距：有没有哪处字距大于行距？
5. 每行字数：回行时头部好找吗？
6. 段落内元素看着像一家人吗？段落之间的边界清楚吗？
7. 每个段落内的元素能再小一点吗？（能不能小到刚好够读）
8. 用了八级杠杆里的哪几级？一级都没用？
9. 图文是叠压、穿插、透叠还是正负空间？遮挡伤到内容了吗？
10. 装饰/纹理的力度：太弱还是喧宾夺主？

做完后：按 1–10 逐条比对导出的大图。**缩略图会骗人**，必须全尺寸看。
